HTML Tags

HTML tags are the building blocks of HTML. They are used to create elements on a webpage, such as headings, paragraphs, links, images, and more. Each tag has a specific purpose and is represented by a pair of angle brackets.

Common HTML Tags

  • <h1> to <h6>: Headings
  • <p>: Paragraphs
  • <a>: Links
  • <img>: Images
  • <ul>, <ol>, <li>: Lists
  • <div>: Division or section
  • <span>: Inline container
  • <form>: Forms for user input

Important HTML Tags

<article>

The <article> tag is used to define an independent piece of content on a webpage. It can be used for blog posts, news articles, or any other self-contained content.

<aside>

The <aside> tag is used to define content that is related to the main content but is separate from it. It can be used for sidebars, pull quotes, or additional information.

<header>

The <header> tag is used to define the header section of a webpage or a specific section. It typically contains introductory content, such as headings, logos, or navigation links.

<main>

The <main> tag is used to define the main content of a webpage. It should contain the primary information that is unique to that page and should not be repeated across multiple pages.

<nav>

The <nav> tag is used to define a section of navigation links. It is typically used for menus, navigation bars, or any other set of links that help users navigate through the website.

<section>

The <section> tag is used to define a thematic grouping of content on a webpage. It can be used to divide the page into different sections, each with its own heading and related content.

<div>

The <div> tag is a generic container used to group elements together. It does not have any specific meaning or semantic value, but it is commonly used for styling purposes or to apply JavaScript functionality to a group of elements.

<span>

The <span> tag is an inline container used to group text or other inline elements. It does not have any specific meaning or semantic value, but it is commonly used for styling purposes or to apply JavaScript functionality to a specific portion of text.

<footer>

The <footer> tag is used to define the footer section of a webpage or a specific section. It typically contains information such as copyright notices, contact information, or links to related content.
